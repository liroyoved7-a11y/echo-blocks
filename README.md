# הד קוביות

משחק דפדפן מקורי של הנחת צורות וניקוי שורות ועמודות, עם קומבו, צלילים ושיא אישי.

## הפעלה מקומית

המשחק משתמש במודולי JavaScript, ולכן יש לפתוח אותו דרך שרת קבצים סטטי ולא ישירות כקובץ `file://`.

1. פתחו מסוף בתיקייה הזו.
2. הריצו `py -m http.server 8000` (או `python -m http.server 8000`).
3. פתחו בדפדפן את `http://localhost:8000`.

אין שלב בנייה, שרת יישום או ספריות להתקנה. נדרש דפדפן מודרני עם תמיכה ב־JavaScript modules וב־Web Audio API.

## פרסום ב־GitHub Pages

1. העלו את תוכן התיקייה הזו לשורש של מאגר GitHub.
2. פתחו במאגר **Settings → Pages**.
3. בחרו מקור פרסום מסוג branch, ואז את `main` ואת `/ (root)`.
4. שמרו והמתינו לסיום הפריסה. קישור האתר יופיע באותו עמוד.

הוראות GitHub Pages עשויות להשתנות; לעדכון העדכני ראו את [מדריך GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site).

## שמירה

הניקוד הגבוה וההגדרות נשמרים ב־`localStorage` בדפדפן הנוכחי. הם אינם מסתנכרנים בין מכשירים או דפדפנים.
